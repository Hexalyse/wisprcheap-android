# WisprCheap Android 0.2.6

- Prevent redirects forwarding provider credentials, private audio/text payloads and sync pairing codes.
- Restrict caller-supplied HTTP clients as well as the shared production client.
- Validate untrusted sync keyring Argon2 parameters before memory allocation or work begins.
- Cap sync response bodies at 2 MiB, including errors and chunked responses.
- Add regression coverage and weekly dependency-update configuration.

Default encryption parameters and sync interoperability vectors are unchanged. Existing custom
keyrings above the supported KDF budgets need rewrapping using a trusted older client.

See the [security review](https://github.com/Hexalyse/wisprcheap-android/blob/v0.2.6/docs/security-review-2026-10-31.md)
for scope, validation and remaining risks.
